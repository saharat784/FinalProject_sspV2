สิ่งที่คุณมีในระบบ:
-ผู้ใช้ทั่วไป:
-สมัคร (Sign Up) / ล็อกอิน
-แก้ไขข้อมูลโปรไฟล์
-ดูข่าวสุขภาพทั้งหมด
-แสดงความคิดเห็นในข่าว
-บันทึกข่าว (เช่น favorite/save)

แอดมิน:
-เพิ่มข่าว
-แก้ไขข่าว
-ลบข่าว
-ดูข้อมูลข่าวทั้งหมด

เทคโนโลยีที่ใช้ทั้งหมด:

Frontend :
ใช้ HTML/CSS + JS (หรือ React/Tailwind ถ้าถนัด)

ประเภท	                         รายการ	                                           รายละเอียด
Backend	                       Go (Golang)	                               ภาษาหลักในการพัฒนา
Web Framework	                  Gin	                                    สร้าง REST API อย่างรวดเร็ว
ORM	                          GORM	                                     เชื่อมต่อและจัดการฐานข้อมูล
Database              SQLite (หรือ PostgreSQL / MySQL)	                   เก็บข้อมูลผู้ใช้ ข่าว ความคิดเห็น
Auth	                    JWT (golang-jwt)	                              ระบบ Login / Token
Password Hash	                 bcrypt	                                         เข้ารหัสรหัสผ่าน
API Gateway       (เลือกใช้)Nginx / Kong / Custom Middleware	สำหรับจัดการ route + auth หลาย service (optional หากมีหลาย service)
Tools อื่น ๆ	                 Postman / Swagger	                        ทดสอบ API / สร้างเอกสาร API
