# Smart Study Planner (SSP)

โครงงานนี้มีวัตถุประสงค์เพื่อพัฒนา ระบบจัดตารางอ่านหนังสืออัจฉริยะ (Smart Study Planner) สำหรับนักเรียนและนักศึกษา ช่วยให้วางแผนการอ่านได้อย่างเป็นระบบและมีประสิทธิภาพ โดยอ้างอิงจากเวลาว่าง ความสำคัญของวิชา และระยะเวลาที่เหลือก่อนสอบ เพื่อแก้ไขปัญหาการจัดการเวลาอ่านหนังสือที่ไม่เหมาะสม

ระบบนี้พัฒนาในรูปแบบ เว็บแอปพลิเคชัน โดยใช้ Django Framework สำหรับทั้ง Backend และ Frontend, PostgreSQL สำหรับฐานข้อมูล, และ Supabase สำหรับจัดเก็บข้อมูลออนไลน์ นอกจากนี้ยังนำ โมเดลภาษา Gemini มาช่วยในการสร้างคำแนะนำและตอบคำถามเชิงวางแผน เพื่อเพิ่มความสะดวกและยืดหยุ่นในการใช้งาน

ผู้ใช้เพียงกรอกข้อมูลพื้นฐาน เช่น รายวิชา วันสอบ และเวลาว่าง ระบบจะสร้างตารางอ่านหนังสือให้อัตโนมัติ แสดงผลในรูปแบบตารางรายวันหรือรายสัปดาห์

ผลลัพธ์ที่คาดหวังคือ ผู้เรียนจะสามารถจัดการเวลาอ่านหนังสือได้เหมาะสมขึ้น ลดความเครียด และทบทวนเนื้อหาได้ครบถ้วน อีกทั้งระบบยังมีความยืดหยุ่นในการปรับแผนตามการเปลี่ยนแปลงในชีวิตประจำวัน Smart Study Planner จึงเป็นเครื่องมือสำคัญที่สนับสนุนการเรียนรู้ด้วยตนเองในยุคดิจิทัลได้อย่างมีประสิทธิภาพ

## 1. บทนำและรายละเอียดโครงงาน

### 1.1 ที่มาและเหตุผล
นักศึกษาจำนวนมากในปัจจุบันประสบปัญหาในการวางแผนการอ่านหนังสืออย่างมีประสิทธิภาพ โดยเฉพาะในช่วงสอบที่มีเนื้อหาจำนวนมากและเวลาจำกัด การอ่านแบบไม่มีแผน หรือการวางแผนด้วยตนเองโดยไม่เข้าใจลำดับความสำคัญของเนื้อหา อาจนำไปสู่การเตรียมตัวสอบที่ไม่พร้อม ทำให้ผลการเรียนอาจไม่เป็นไปตามที่คาดหวัง และเกิดความเครียดจากการจัดการเวลาที่ไม่ดี

ระบบการจัดตารางอ่านหนังสือส่วนใหญ่ในปัจจุบัน เช่น การใช้กระดาษ ปฏิทิน หรือแอปพลิเคชันปฏิทินทั่วไป ยังคงเป็นแบบพื้นฐาน ไม่สามารถปรับเปลี่ยนตามพฤติกรรมผู้ใช้ หรือแนะนำตามความยากง่ายของวิชาได้ ทำให้ผู้ใช้ต้องใช้เวลาและแรงในการวางแผนด้วยตนเอง ซึ่งอาจไม่เหมาะสมกับแต่ละบุคคล

ด้วยเหตุนี้ เราจึงมีแนวคิดที่จะพัฒนาระบบ Smart Study Planner ที่สามารถจัดตารางอ่านหนังสือให้เหมาะสมกับเป้าหมายของผู้ใช้ โดยอิงจากข้อมูลต่าง ๆ เช่น ระยะเวลาในการเตรียมตัว วิชาที่ต้องสอบ ความยากของเนื้อหา และพฤติกรรมการอ่านของผู้ใช้ ระบบนี้จะช่วยให้ผู้ใช้สามารถเตรียมตัวสอบได้อย่างมีประสิทธิภาพและตรงจุดมากยิ่งขึ้น ลดความเครียดและเพิ่มโอกาสในการประสบความสำเร็จในการเรียน

### 1.2 วัตถุประสงค์
* **1.2.1** เพื่อพัฒนาและออกแบบระบบ Smart Study Planner ที่สามารถจัดตารางอ่านหนังสือส่วนบุคคลได้อย่างมีประสิทธิภาพ โดยพิจารณาจากข้อมูล เช่น ระยะเวลาในการเตรียมตัว วิชาที่ต้องสอบ ความยากของเนื้อหา และพฤติกรรมการอ่านของผู้ใช้
* **1.2.2** เพื่อสร้างกลไกการปรับตารางอ่านหนังสืออัตโนมัติ ที่สามารถปรับเปลี่ยนแผนการอ่านได้ตามความคืบหน้า หรือเมื่อมีการเปลี่ยนแปลงปัจจัยภายนอก เช่น วันสอบเลื่อน เพื่อให้ผู้ใช้สามารถปรับตัวได้ทันท่วงที
* **1.2.3** เพื่อประเมินประสิทธิภาพและความพึงพอใจของผู้ใช้งาน ต่อระบบ Smart Study Planner ในด้านความสะดวกในการใช้งาน การช่วยเพิ่มประสิทธิภาพในการจัดตารางอ่านหนังสือ และลดความกังวลในการเตรียมตัวสอบ

### 1.3 ขอบเขตของโครงงาน
โครงงานนี้เป็นการพัฒนา Smart Study Planner – ระบบจัดตารางอ่านหนังสืออัจฉริยะ ในรูปแบบเว็บแอปพลิเคชัน (Web Application) โดยมีขอบเขตดังนี้:
* พัฒนาระบบสำหรับใช้งานบนเว็บเบราว์เซอร์ รองรับระบบปฏิบัติการ Windows, macOS, Linux และอุปกรณ์พกพา เช่น Android และ iOS
* ผู้ใช้สามารถกรอกข้อมูลวิชาที่ต้องสอบ, วันสอบ, เวลาว่างในแต่ละวัน และระดับความสำคัญของแต่ละวิชา
* ระบบจะประมวลผลข้อมูลเพื่อสร้างตารางอ่านหนังสือให้เหมาะสมกับผู้ใช้ โดยใช้เทคนิคการจัดลำดับความสำคัญและการจัดตารางเวลา
* กลุ่มเป้าหมายของระบบคือ นักเรียนหรือนักศึกษาที่ต้องการวางแผนการอ่านหนังสืออย่างมีประสิทธิภาพ
* ระบบไม่ครอบคลุมการวิเคราะห์ผลการเรียน, การประเมินความเข้าใจของผู้ใช้, การเชื่อมต่อกับปฏิทินภายนอก และไม่รองรับการแนะนำคอร์สหรือบทเรียนเพิ่มเติม

## 2. ฟังก์ชันการทำงานหลักของระบบ (System Features)

### 2.1 การจัดตารางอ่านหนังสืออัตโนมัติ (AI Study Scheduling)
* คำนวณและจัดสรรตารางการอ่านหนังสือล่วงหน้า โดยประมวลผลผ่านโมเดลภาษา Gemini ร่วมกับเงื่อนไข:
  * ช่วงเวลาว่างจริงของผู้ใช้ในแต่ละวัน (User Availability)
  * ระดับความยากง่าย (Difficulty) และระดับความสำคัญ (Importance) ของแต่ละวิชา
  * วันและเวลาสอบ (Exam Date) เพื่อจัดลำดับความสำคัญของวิชาที่ใกล้สอบก่อน
  * ระยะเวลาในการอ่านต่อรอบและเวลาพัก (Session Duration & Break Duration)
* การแจกแจงหัวข้อย่อยในการอ่าน (Topic Breakdown) เพื่อให้การอ่านแต่ละครั้งมีเป้าหมายที่ชัดเจน

### 2.2 การสรุปเนื้อหาและแบบทดสอบประเมินตนเอง (Summaries & Quizzes)
* **การสรุปเนื้อหาบทเรียน (Content Summary):** สร้างสรุปใจความสำคัญของหัวข้อที่ศึกษา เพื่อช่วยให้ทบทวนได้อย่างรวดเร็ว
* **แบบทดสอบปรนัย (Dynamic Quiz):** สร้างข้อสอบแบบเลือกตอบตามวิชาและหัวข้อ เพื่อให้ผู้ใช้สามารถประเมินตนเองหลังอ่านเสร็จ
* **ระบบตรวจและเฉลย:** แสดงผลคะแนน พร้อมเฉลยคำตอบที่ถูกต้อง

### 2.3 การติดตามความคืบหน้า (Progress Tracking)
* บันทึกสถานะการอ่านหนังสือแต่ละเซสชัน (สำเร็จ / ยังไม่สำเร็จ)
* จัดเก็บประวัติการทำแบบทดสอบและประวัติการสรุปเนื้อหา
* ระบบแนบไฟล์เอกสารประกอบการเรียนรายวิชา

## 3. สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)

* **Backend & Web Framework:** Python, Django Web Framework
* **Frontend:** Django Templates, HTML5, CSS3, JavaScript
* **Database & Cloud Storage:** PostgreSQL, Supabase (Cloud Database / Storage), SQLite (สำหรับ Local Development)
* **Artificial Intelligence (AI):** Google Generative AI (Gemini Flash Model)
* **Deployment & Environments:** รองรับการ Deploy บน Cloud Platforms (เช่น Render, Gunicorn, WhiteNoise)

## 4. โครงสร้างโปรเจกต์ (Project Structure)

```text
smartstudyplannerV2/
├── core/                        # Django Application หลัก
│   ├── ai_service.py            # ส่วนเชื่อมต่อ Gemini AI สำหรับจัดตาราง สรุปเนื้อหา และสร้างควิซ
│   ├── models.py                # โครงสร้างฐานข้อมูล (Users, Subjects, StudySessions, Quizzes ฯลฯ)
│   ├── views.py                 # Business Logic และส่วนประมวลผลคำขอจากผู้ใช้
│   ├── forms.py                 # แบบฟอร์มสำหรับรับและตรวจสอบความถูกต้องของข้อมูล
│   ├── urls.py                  # เส้นทาง URL ของฟังก์ชันต่าง ๆ ภายในระบบ
│   ├── templates/               # ไฟล์ส่วนแสดงผล HTML Templates
│   └── static/                  # ไฟล์สไตล์ชีท CSS, JavaScript และรูปภาพประกอบ
├── smart_study_planner/         # โฟลเดอร์การตั้งค่าระดับโปรเจกต์ (settings.py, urls.py, wsgi.py)
├── media/                       # โฟลเดอร์เก็บไฟล์ที่ผู้ใช้อัปโหลด (ไฟล์วิชา, เอกสาร)
├── requirements.txt             # รายการไลบรารีและแพ็กเกจที่ระบบจำเป็นต้องใช้งาน
├── build.sh                     # สคริปต์สำหรับการติดตั้งและ Build บน Server
├── manage.py                    # คำสั่งจัดการระบบของ Django
└── .env.example                 # ตัวอย่างการกำหนดค่า Environment Variables
```

## 5. การติดตั้งและเริ่มต้นใช้งาน (Installation & Setup)

### 5.1 ความต้องการของระบบ (Prerequisites)
* Python 3.10 ขึ้นไป
* Git
* บัญชี Google AI Studio สำหรับรับ Gemini API Key
* ฐานข้อมูล PostgreSQL หรือ Supabase (สำหรับ Production) หรือใช้ SQLite (สำหรับ Development)

### 5.2 การ Clone โครงการ
```bash
git clone <repository-url>
cd smartstudyplannerV2
```

### 5.3 การสร้าง Virtual Environment
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 5.4 การติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### 5.5 การตั้งค่า Environment Variables
สร้างไฟล์ `.env` ที่โฟลเดอร์หลักของโปรเจกต์ โดยอ้างอิงจาก `.env.example`:
```env
SECRET_KEY=your_django_secret_key
DEBUG=True
GEMINI_API_KEY=your_gemini_api_key

# ข้อมูลการเชื่อมต่อฐานข้อมูล PostgreSQL / Supabase
DB_NAME=your_db_name
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=your_db_host
DB_PORT=5432
```

### 5.6 การ Migrate ฐานข้อมูล
```bash
python manage.py makemigrations
python manage.py migrate
```

### 5.7 การรันเซิร์ฟเวอร์ทดสอบ
```bash
python manage.py runserver
```
เข้าใช้งานผ่านเว็บเบราว์เซอร์ที่ `http://127.0.0.1:8000`
